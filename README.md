# groupbees Homebrew tap

[Homebrew](https://brew.sh) formulae for groupbees tools, for macOS and Linux.
Each one lives in [Formula/](Formula/).

## Getting started

```sh
brew install groupbees/tap/<formula>
```

For example, [pollen](https://github.com/groupbees/pollen):

```sh
brew install groupbees/tap/pollen
```

`brew upgrade` picks up new releases.

## Contributing

The formulae are generated and pushed here by each project's release
workflow, so this repository is not edited by hand: a change to a formula
belongs in the project that publishes it.
